## Source and scientific integrity
- USGS STAC item: https://stac.astrogeology.usgs.gov/api/collections/mro_hirise_socet_dtms/items/DTEEC_045994_1985_046060_1985_U01 (HTTP 200 independently checked).
- HiRISE DTM source spatial posting approx 1.01655 meters, Mars 2015 ocentric equirectangular CRS (IAU 49910). The observed data were sampled to a 257×257 grid, covering a 1,600 meter projected window centered at 18.43 N / 77.445 E.
- Coverage 100%. Measured altitudes within the window approx -2592.63 m to -2544.04 m relative to the Mars areoid. The color texture is an image visualization, not synthetic elevations.
- Orthoimage and elevation samples were aligned using matching projected windows.
- East-west horizontal lengths use the local cosine-latitude correction for Mars equirectangular X coordinates. Vertical exaggeration changes graphics only, not path data.

## Scientific and operational limitations
- Route costs and the 28-degree cutoff are explicitly illustrative, NOT safety-engineered for a rover or astronaut.
- DTM stereo artifacts, Figure of Merit pixel quality and positional uncertainties require independent inspection for mission-relevant decisions. A ~6m resampled grid cannot see small boulders.
- No radiation, oxygen, live weather, battery, friction, or route-safety estimates are claimed.
- 3D relief is a local 1.6 km region; no full-planet terrain streaming or public production deployment.
- The recorded QA was done on the standalone prototype before publication to this independent repository; it is not an official NASA-endorsed or team-integrated application.
- The recorded localhost HTTP service was accessible on the testing device only; clones can run their own server or use the public Pages demo once deployed. On a new device, run npm install, npm test, and npm run preview first.
